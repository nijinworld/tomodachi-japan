### 授業の記録について

【ともだちじゃぱん】では、授業をよりよくするために、授業中のやりとりを記録し、
先生の授業の進め方を振り返る仕組みを使っています。
どんな記録を、何のために、誰が見るのかを、正直にお伝えします。

---

### 1. 何を記録しますか

**授業中の会話を文字にしたもの（書き起こし）です。**

- お子さまが話したことばが、文字として記録されます
- 記録するのは**授業のはじめの15分**です
- 【映像と音声そのものは保存しません／保存します：保存する場合は期間と保管場所を書く】

### 2. 何のために使いますか

**先生の授業の進め方を見直すためです。**

たとえば、こういうことを数えています。

- 先生が話している時間の割合
- 8人のうち、話す番が一部の子に偏っていないか
- 先生が質問してから、子どもが答えるまでの待ち時間
- 言い間違いを先生が直したあと、子どもが言い直せているか

**お子さまの成績をつけるためではありません。**
このシステムは、子どもに点数をつけません。順位もつけません。

### 3. 誰が見ますか

| 見る人 | 見えるもの |
|---|---|
| 担任の先生 | 自分の授業の記録だけ |
| その先生を支える担当者 | 担当する先生の授業 |
| 運営 | 全体 |
| **外部の評定者** | **書き起こしだけ。お子さまの名前も、先生の名前も見えません**（「子ども1」と表示されます） |

**誰がいつ記録を見たかを、システムが残しています。** ご希望があればお見せします。

### 4. どのくらい保存しますか

**【180】日です。** その後は、**お子さまが話したことばを消します。**

消したあとに残るのは、「発話の回数」「待ち時間の秒数」といった**数値だけ**です。
誰が何を言ったかは残りません。

### 5. アンケートについて

授業について、お子さまに【隔週】でアンケートをお願いすることがあります。

**誰が何と答えたかは、システムに残りません。** 回答に個人の情報を保存しない作りにしています。
先生に伝わるのは、クラス全体をまとめた結果だけです。
回答が【4】件に満たないときは、先生にも見せません（誰が書いたか分かってしまうためです）。

答えたくない質問は飛ばしてかまいませんし、アンケート自体に参加しなくてもかまいません。
授業の扱いは変わりません。

### 6. いつでもやめられます

**同意はいつでも撤回できます。** 撤回のご連絡をいただいた時点で、

- それ以降、お子さまの発話は記録しません
- **すでに記録されている分も、ご希望があれば消します**（数値の集計だけが残ります）
- 授業やクラスの扱いは、いっさい変わりません

撤回のご連絡先：【　　　　　　】

### 7. 安全について

お子さまの安全に関わることが起きた場合、**私たちは事業のすべてを止めて、公表します。**
売上や実験の都合より上に置く、と決めています。

### 8. 質問について

分からないことは、どんなことでも聞いてください。
「なぜ記録するのか」「何が残るのか」に答えられないまま続けることはしません。

## 記録のしかた（運営向け）

同意をいただいたら、**必ずシステムに記録してください。**

1. `#/people`（人とクラス）を開く
2. その子の行の「記録」を押す
3. 誰から・いつ・どの方法で同意を得たかを入れる

**記録がない子どもが名簿にいるクラスは、書き起こしを取り込めません。**
取り込もうとすると、その子の名前を出して止まります。これは仕様です。

撤回のご連絡を受けたら：

1. `#/people` から「同意」→ 撤回（画面から、または API）
2. すでに入っている発話を消す：

```bash
node scripts/purge.js --student <その子のID>
```

3. ご家庭に、消したことをお伝えする

**「消しました」と言う前に、必ず実行してください。**
