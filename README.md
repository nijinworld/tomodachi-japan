# Ranius日本語

**オンライン日本語スクール「ともだちじゃぱん」の運用システム。**
同時に、教師トレーニングシステム Ranius の測定器です。

株式会社NIJIN ／ 2026年8月

---

## 30秒でわかる、このシステムが測っているもの

> **メンター1人が、同時に何人のファシリテーターを伸ばせるか。**

売上でも生徒数でもありません。事業計画のすべての論拠が、この一つの数字に載っています。
だからこのシステムには、**ダッシュボードに売上がありません。**

そして、いまこの数字は**まだ測れていません**。測り始めたところです。
画面は「未測定」と「0」を、はっきり区別して表示します。

## 動かす

**Windows**：`はじめて動かす.cmd` をダブルクリック

**それ以外**：

```bash
node scripts/seed.js     # デモデータを作る（既存のデータは消えます）
node server/index.js     # → http://localhost:5173
npm test                 # テスト（件数は実行して確認。うち11件が内部監査の指摘を固定）
npm run backup           # data/ を backups/ に控える
```

Node 18以上。**`npm install` は要りません。依存パッケージはゼロです。**

### ログイン

デモデータの合言葉は全員 `ranius-demo-2026` です。

| 入れるID | 誰として入るか |
|---|---|
| `u_admin` | 運営（全部見える） |
| `u_mentorA` | メンター |
| `伊藤（デモ）` | 先生（自分のものだけ見える） |
| `u_rater1` | 外部評定者（盲検の採点しか出ない） |

実データを入れる前に、必ず入れ直してください。

```bash
node scripts/set-passcode.js --list          # 誰がいるか
node scripts/set-passcode.js <ID> <合言葉>    # 設定する
```

## 何ができるか

| 画面 | 何をするところか | 根拠 |
|---|---|---|
| **今週** | 律速（メンター担当数）と、まだ測れていないことの一覧。**先生には自分の分だけ出る** | — |
| **書き起こしの取り込み** | Zoom / Meet / VTT / SRT / CSV を貼る → 話者を対応づける → 採点まで自動 | — |
| **授業と採点** | 冒頭15分を6観点で採点。**すべてのスコアに時刻つきの根拠が付く** | 冒頭15分で約6割の信頼性（MET） |
| **盲検の採点** | 外部評定者専用。名前・アーム・AIスコアが**構造的に見えない** | 2名×2本で .67（MET） |
| **先生** | 本人の過去とだけ比べる推移。**順位は作らない** | 事業計画「やらないと決めていること」 |
| **子どものアンケート** | 頻度尺度・主語は「わたし」・複数項目。**返し方の3手順を記録する**。「ともだち（所属感）」は点数化せず時系列だけ出す | 設計あり d=0.568／なし d=0.050 |
| **アーカイブ** | 30秒クリップ＋**視聴の問い**。問いに答えないと視聴を記録しない | 視聴ガイドの有無が効果を分ける |
| **メンターの記録** | 毎日1行。ここからしか担当数を計算しない（推定しない） | **事業の全論拠** |
| **評価者間一致** | 盲検2名の二重コーディング → 二次重みつきカッパ。目標 .65 | 2名×2本で .67（MET） |
| **器具の健全性** | 観点が天井・床に張りついていないか。観点どうしの相関 | ルーブリックは未検証 |
| **費用** | ingredients method。受講者時間を **0円／最低賃金／同等職** の3通りで計算 | 「安さの正体」を先に説明するため |
| **A/B** | アーム単位の集計のみ。個人は出さない | 12月のフィージビリティ・スタディ |
| **撤退基準** | 触れたら警告。**セーフガーディング事案は1件で全機能停止** | Bridge International の教訓 |
| **モデル版** | LLM＋プロンプト＋ルーブリックの凍結と再スコア | 「モデルを凍結した」と言うために |
| **人とクラス** | 先生・メンター・評定者・クラス・子どもの登録と合言葉 | — |
| **書き出し** | 外部解析用のCSV 8種（Excelで文字化けしない） | AEA事前登録・R/Stata用 |
| **チームの週次** | 4〜8名で「次の1手」を1つだけ宣言する記録 | 返し方の設計＝効果のほぼ全部 |

## このシステムが、構造としてやらないこと

コードで機械的に止めています。仕様変更で外す前に、事業計画側の合意を取ってください。

| やらないこと | どうなるか |
|---|---|
| 先生をランキングする | `GET /api/lessons?sort=...` は **403** |
| 人格に触れる所見を残す | 「熱意」「やる気」などを含むと **422** |
| 問いのないアーカイブ視聴を記録する | **400** |
| 回答4件未満のアンケートを先生に返す | 集計を返さない |
| 公表しないまま事案をクローズする | **400** |
| セーフガーディング事案が開いている間に動く | 全API **423**（確認と記録以外） |
| 評定者に先生の名前・アーム・AIスコアを見せる | `/api/blind/*` 以外から授業に到達できない |
| 先生が他の先生の記録を見る | **403**（自分のものだけ。一覧もサーバ側で絞る） |
| アンケートの回答に子どものIDを残す | **保存しない**（誰が答えたか、システムにも分からない） |
| ヘッダ・クエリ・body で「自分は誰々です」と名乗る | 署名つきクッキー以外は見ない |
| 先生が「メンターの所見」を自作して担当数を動かす | **403** |
| 子ども用アンケートの部分回答・連投 | 400 ／ 429（名簿+4件で打ち止め） |
| 保護者の同意がない子どもの発話を保存する | 取り込み時に **400 CONSENT_REQUIRED** |
| 書き起こしを保存期間を超えて持ち続ける | `purge.js` でことばだけ消す（数値は残す） |

**AIはスコアを出しません。** スコアは決定的な計算で出します。
LLMが出すのは所見の文面だけです。理由は「凍結したモデルは再現できなければならない」から。

## 中身

```
ranius-nihongo/
├── spec/          仕様。数字はコードではなくここに置く
│   ├── rubric.ja.json     6観点・帯・冒頭15分（凍結の対象）
│   ├── survey.ja.json     子どものアンケートと返し方
│   ├── evidence.json      画面に出る数字の出典と検証状態
│   ├── kill-criteria.json 撤退基準
│   ├── schema.sql         将来のDB移行の叩き台（いまは未使用）
│   └── api.md             API一覧
├── prompts/       所見プロンプト（凍結の対象）
├── server/        依存ゼロのAPI（lib/ に 認証・採点・IRR・費用・担当数・取り込み・書き出し）
├── web/           画面（フレームワークなし）＋ survey.html（子ども用・ログインなし）
├── data/          データの実体（JSON）
├── scripts/       seed / freeze-model / set-passcode / backup / purge
├── test/          npm test（5本。件数は実行して確認）
└── docs/
    ├── エンジニア引き継ぎ書.md   ← エンジニアはまずこれ
    ├── 運用手順.md               ← 現場はまずこれ
    ├── 保護者への説明.md         ← 同意をもらうときのひな型
    └── 開発の分担.md             ← 複数のチャットで並行して進めるとき
```

## ⚠️ いま入っているのはデモデータです

`node scripts/seed.js` が作った、固定シードの架空データです。実績ではありません。
画面の上に常に警告が出ます。**この画面のスクリーンショットを資料に貼らないでください。**

認証と仮名化は入っています。実データの前に**まだ**必要なこと
（HTTPS・保護者への説明と同意・保存期間・閲覧ログ）は `docs/エンジニア引き継ぎ書.md` 6.4 にあります。
